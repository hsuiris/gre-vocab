# GRE 單字複習 App 設計規格

日期:2026-07-18

## 目標

一個可以複習、練習 GRE 單字的 React Native App(Expo),目標之後可上架 App Store / Google Play。核心練習方式是翻卡:

- 英猜中文意思
- 中猜英文單字

每張卡可展開查看詳情:範例句、發音、字根字尾說明。

## 技術選型

- **React Native + Expo**,與既有 HeartU-Draw 專案技術棧一致,可用 EAS Build 產出 iOS/Android 安裝檔
- **expo-speech**:文字轉語音,朗讀單字發音,不需錄音檔
- **@react-native-async-storage/async-storage**:本地儲存進度與熱點圖資料,不需登入、不需後端、不需資料庫
- **`words.json`**:建置期一次性生成的靜態單字資料,打包進 App 當 bundled asset,執行期完全離線可用

不需要後端 API、不需要伺服器、不需要使用者帳號系統。

## 資料層

### 來源

`~/Desktop/GRE词汇红宝书赵丽.pdf`(66 頁,講義筆記體,涵蓋 A~parameter,每字有中文意思與字根聯想,但無英文範例句)。

### `words.json` 結構

```json
{
  "word": "abate",
  "pos": "v.",
  "meaning": "減輕、緩和",
  "example": "The storm began to abate as the night wore on.",
  "roots": "a- (加強) + bate (打擊，源自拉丁文 batre) → 打到力道減弱"
}
```

### 生成流程(建置期,一次性)

1. `pdftotext -layout` 把 PDF 轉純文字(已驗證可行)
2. 撰寫 parser 腳本,從文字中抓出 A~P 開頭、格式較完整的詞條(單字 + 中文意思 + 字根聯想),整理成初版 JSON
3. 分批(每批約 50-100 字)用 AI 處理這批詞條:補上範例句(PDF 沒有)、把字根說明整理成通順敘述、標注詞性
4. P~Z 沒有原始資料來源的部分,同樣分批用 AI 直接生成完整詞條(意思、範例句、字根說明),涵蓋 GRE 常見高頻字
5. 最終產出完整 `words.json`(約 3000 字),打包進 App

此步驟是全案最耗時的部分,實作計畫會拆成明確批次任務。

## 練習邏輯

### 兩種模式

- 英 → 中:卡片正面顯示英文單字,翻卡看中文意思
- 中 → 英:卡片正面顯示中文意思,翻卡看英文單字

兩種模式**共用同一套進度紀錄**(同一個字不分方向,只有一個熟悉度狀態)。

### 記憶追蹤:Leitner 系統

- 5 個盒子(box 1-5),對應複習間隔:1 天 / 2 天 / 4 天 / 7 天 / 14 天
- 翻卡看到答案後,使用者按「認識」或「不認識」:
  - 認識 → 移到下一個盒子(最高第 5 盒)
  - 不認識 → 打回第 1 盒
- 每個字記錄:目前盒子等級、下次複習日期,存在 AsyncStorage
- 尚未練習過的字視為「新字」,預設下次複習日期為今天,一開始就會出現在待複習清單
- 首頁「待複習」= 今天日期 ≥ 該字下次複習日期的字(含所有新字)

### 卡片詳情(展開,不影響 Leitner 判定)

- 範例句
- 喇叭圖示:按下用 `expo-speech` 朗讀單字
- 字根字尾說明

## 畫面

1. **首頁**
   - 選擇練習方向(英→中 / 中→英)
   - 顯示今日待複習字數
   - 學習天數熱點圖(見下)
2. **練習卡片畫面**
   - 翻卡互動 + 認識/不認識按鈕
   - 可展開的詳情區塊
3. **統計畫面(最小版)**
   - 各盒子目前字數
   - 重置進度選項

## 學習天數熱點圖

- 每次「認識/不認識」判定都算一次複習,依日期累加次數:`{"2026-07-18": 23, ...}`,存在 AsyncStorage
- 首頁用純 View 格子畫出類似 GitHub 貢獻圖的熱點圖(近 12-16 週,顏色深淺依當天複習次數)
- 不另外安裝圖表套件,手刻可橫向捲動的格子網格即可

## 上架

Expo EAS Build 產出安裝檔。正式上架需要開發者帳號(iOS $99/年、Google Play 一次性 $25),此為之後的步驟,不影響開發階段。

## 範圍界定

- 不做:多裝置同步、使用者帳號、後端 API、社群/排行榜功能
- 資料一次生成到位(A-Z 約 3000 字),不做漸進式擴充
